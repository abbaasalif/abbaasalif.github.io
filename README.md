# abbaasalif.github.io

Static, dependency-free portfolio for GitHub Pages.

## Publish

Copy these files into the root of `abbaasalif/abbaasalif.github.io` and push to `main`. In the repository’s Pages settings, choose **GitHub Actions** as the source.

## Before publishing

- Review the publication selection and add any additional paper, code, slides, or video links you want surfaced.
- The three finalized PDF resume variants are included under `assets/resumes/` and wired to their download cards.
- Review public-safe project wording and add paper, code, poster, or demo URLs where available.
